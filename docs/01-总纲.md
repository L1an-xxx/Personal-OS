# 01 · 总纲（共同基准）

> 来源：个人发展系统 v1.0（2026-10-09）· 本文为精简基准，供每月复盘与调整。

## 目标
- **终极**：数字游民，最终以交易为生；产品 + 交易是两大引擎，主业是过渡现金流。
- 长期：增加**选择权**，重掌生活主动权；不以单一收入数字衡量。
- 收入梯度（参考，非承诺）：`2万 → 3万 → 5万 → 6万 → 10万/月`
- 交易梯度（参考）：`稳定盈利 5千 → 1万 → 2万 → 5万 → 10万/月`
- 其他：Go/Python/AI/Web/自动化 · 产品 · 英语 · 算法 · 思考与设计 · 健身（腹肌）· 个人数字平台

## 三种收入引擎
| 引擎 | 作用 | 原则 |
| --- | --- | --- |
| 主业 | 现金流/社保/职业资本 | 先建可靠底座 |
| 产品/业务 | 第二收入曲线 | 小 MVP，尽早验证需求 |
| 交易/资本 | 资本收益 | 先验证策略与风控，不当工资替代 |

## 五条主线
1. **主业与现金流**：实习→转正；找改进点；评估岗位价值。
2. **技术**：Go/Python/AI/工程化，项目驱动，产出可复用成果。
3. **产品化平台**：小而真实的问题 → MVP → 验证需求 → 迭代。
4. **合约交易**：机制与风控 → 记录复盘 → 策略规则 → 验证 → 观察 → 才加资金。
5. **个人数字平台（本仓库）**：记录资产/收支/交易/学习/博客，服务自己。

## 现状（2026-10）
- 主业：广告行业公司实习，AI 编码开发运营工具；9–6 双休；2–3 个月可转正。
- 背景：西电软件工程硕士；华为计算产品线 2.5 年（Go 分布式 DonauKit）；COT 芯片设计 6 个月。
- Gap 一年：半年休息 + 半年外汇黄金合约交易（有盈利，无稳定系统）。
- 简历：`D:\Code\CV\cv 3.0.md`
- 记录：资产 · 收支 · 合约交割单 · 力扣（Web 应用实现）。

## 三项习惯
- 英语：每天 30–45 分钟
- 算法：每周数次
- 健身：每周 3–4 次

## 时间框架
- 29→30 岁：校准期（小规模真实试验）
- 30→35 岁：第一个五年（定方向，不锁死逐年计划）
- 每月：复盘（结果 + 过程证据）

## 投入比例（试运行起点，可调）
技术 30% · 产品 25% · 个人平台 15% · 交易 15% · 英语 7% · 算法 5% · 健身单独安排

## 执行原则（精简）
1. 不同时把九项做到极致；先现金流底座。
2. 用真实产出检验能力（代码/产品/交易记录 > "学过很多"）。
3. 不为忙碌而忙碌：每条线能回答「解决什么 · 留下什么 · 如何判断有效」。
4. 计划随证据调整；每月保留正反馈；保持独立判断。
