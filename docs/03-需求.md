# 03 · 需求基线

> Personal OS = 前后端分离 Web 应用。技术栈待定；本文件只定「做什么」。

## 模块
1. **资产**：净值曲线、分类（现金 / 账户 / 持仓）
2. **收支**：收入 / 支出、分类、月度汇总
3. **交割单**：逐笔（品种 / 方向 / 手数 / 入场 / 出场 / 止损 / 盈亏 / 复盘）→ 自动算胜率、期望、R 倍数、最大回撤
4. **力扣**：题号 / 难度 / 关键点 / 状态

## 约束
- 前后端分离；单用户、本地优先；数据可导出（json / csv）
- 数据归自己（个人数字平台定位）

## 里程碑（建议顺序）
1. 交割单 + 分析（核心，验证交易系统）
2. 资产 + 收支
3. 力扣

## 交割单分析指标（核心）
- 胜率 = 盈利笔数 / 总笔数
- 期望 = Σ盈亏 / 总笔数（平均每笔盈亏）
- R 倍数 = 盈亏 / 风险；风险 = |入场−止损| × 手数 × 合约乘数
- 最大回撤 = 累计盈亏曲线的最大峰谷回撤

> 注意：① 手续费 / 点差要计入，否则期望虚高；② 样本 < 30–50 笔时，指标统计意义不足，别据此下结论。
